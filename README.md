# 微光 Lumen

会陪你听歌的安卓播放器。懂你此刻，也懂你曲库里的每一首歌。

门户：https://wg.ivyea.com

> 开发中，当前阶段 M1（播放器本体）。

## 是什么

- **此刻**：AI 伙伴「微光」。说一句「有点累」，它从你自己的曲库里挑歌
- **播放**：频谱粒子环、逐字歌词、AI 解读歌词
- **情绪星图**：曲库按明亮度和能量排成星空，画一条线就生成一张歌单

音源只用本地音乐和你自建的服务器（Navidrome / Jellyfin / WebDAV），不抓任何在线平台。AI 用你自己的 key（兼容 OpenAI 格式的接口都行），不填也能用。

完整方案见 [docs/方案.md](docs/方案.md)。
