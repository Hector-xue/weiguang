# 微光 Lumen

懂你此刻的听歌伙伴。曲库还是你的网易云，微光按心情排歌、记得你的习惯、陪你读歌词。

门户和下载：https://wg.ivyea.com

## 能做什么

- **情绪找歌**：选一个心情，微光在你曲库的情绪星图上走一条路。前几首陪着你，后面一点点亮起来
- **懂你**：从你自己的听歌记录里学「这个点你常听什么」；对话点歌按你的口味只从你的曲库里挑
- **歌词**：整首滚动歌词带翻译，点一句让 AI 讲给你听
- **曲库**：同步网易云歌单，歌单封面用第一首歌的专辑图
- **播放页**：频谱粒子环，整页颜色随封面流动
- **悬浮光球**：在网易云里也能一键回来

## 怎么做到的

微光不提供音源，也不登录你的网易云账号：

- 通过安卓的媒体会话读网易云正在放什么、控制播放（需要「通知使用权」）
- 通过网易云开放给车机的浏览接口读你的歌单
- 点歌用网易云的歌曲链接，会切到网易云播放
- 歌词和封面按歌曲 ID 查网易云公开接口
- AI 用你自己的密钥，兼容 OpenAI 格式的接口都行（DeepSeek、Kimi、硅基流动、本地 Ollama），不填也能用

这些路子都在真机上验证过，结论见 [docs/方案.md](docs/方案.md)。

## 目录

- `android/`：App（Kotlin + Jetpack Compose）
- `probe/`：验证工具，用来测网易云哪些接口能用
- `site/`：门户页
- `docs/`：方案、概念图、发版说明

## 构建和发布

全部在 GitHub Actions 上跑：

- 推到 main：编出开发版，发到 Release `dev`（预发布）
- 打 `v*` tag：编出正式版，说明取 `docs/releases/<tag>.md`
- 编完会触发门户页发布，把安装包一起放到 `wg.ivyea.com/download/`
