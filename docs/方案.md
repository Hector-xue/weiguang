# 微光 Lumen · 安卓 AI 音乐播放器方案

> 自用 + 开源。概念图：`docs/mockup.html`（实时动效）/ `docs/mockup.png`；门户 https://wg.ivyea.com

## 1. 定位

**一个会陪你听歌的播放器。** 播放器管"放"，一个 AI 伙伴（光球「微光」）管"懂"：懂你此刻的状态、懂你曲库里每首歌的感觉，用聊天和粒子动效把两者连起来。

不做的事：不做在线曲库，不爬任何平台（开源项目碰不得版权）。

## 2. 音源（可插拔）

| 源 | 说明 | 阶段 |
|---|---|---|
| 本地文件 | MediaStore 扫描，读标签/内嵌封面/LRC | MVP |
| 自建服务器 | Subsonic/Navidrome、Jellyfin、WebDAV（NAS 用户刚需） | P2 |
| AI 生成 | 接 Suno 类 API，"为此刻写一首" | P3 |

接口统一为 `MusicSource`，曲库/播放/AI 都只认这一层。

## 3. 功能设计

### 3.1 此刻（首页）
- **微光光球**：粒子球面跟随节拍呼吸；状态切换＝颜色/转速变化（聆听中→思考中→说话中）
- **微光在想…**：结合时间/天气/最近在听，生成一两句话 + 推荐 3 首（天气用 Open-Meteo，免 key）
- **对话点歌**：「有点累」「来点雨天的」「刚那首换成钢琴版」→ AI 从**你的曲库**里挑，给快捷回复
- **哼唱/语音输入**：语音转文字点歌；哼唱识别列 P3

### 3.2 播放页
- **频谱粒子环**：围绕封面的点阵频谱，高能量处迸出火花
- **封面取色**：整页渐变跟随封面主色流动
- **AI 歌词**：逐字高亮；「解读这句」→ 意象/背景/情绪
- 无歌词的歌：本机识别生成（Whisper 小模型，P3）

### 3.3 情绪星图（招牌功能）
- 每首歌按 **明亮度 × 能量** 落成一颗星，颜色＝情绪簇
- **画一条线 → 生成歌单**：从左下（低落）拖到右上（开心），按路径排出渐进歌单（情绪疗愈式过渡）
- 点一片区域＝情绪电台；长按一颗星＝"更多像它的"
- 星的坐标来源：本机音频特征（节奏/响度/调式/频谱质心）为主，AI 根据歌名歌手补标签为辅

### 3.4 其他
- 智能歌单：一句话建歌单、自动去重/补全封面歌词
- 听歌回顾：每周一段 AI 写的"你这周的声音日记"
- 睡眠/专注模式：渐弱定时 + 光球变暗变慢
- 桌面小组件 + 锁屏/通知栏控制（Media3 自带）

## 4. 技术方案

| 层 | 选型 | 理由 |
|---|---|---|
| UI | Kotlin + Jetpack Compose | 原生动效最顺，粒子直接画 |
| 粒子/光效 | Compose Canvas + **AGSL Shader**（Android 13+），12 以下降级 Canvas | 光球、辉光、流动渐变放 GPU |
| 播放 | Media3 ExoPlayer + MediaSessionService | 后台/通知/蓝牙/车机一套搞定 |
| 频谱 | 自定义 `AudioProcessor` 截 PCM 做 FFT | **不用** `Visualizer` API（要录音权限，用户会被吓到） |
| 数据 | Room + 歌曲特征表 | 星图坐标离线算好存库 |
| AI | OpenAI 兼容接口，自填 key（DeepSeek/Kimi/本地 Ollama 都行） | 开源必须 BYOK，不内置 key |
| 构建 | GitHub Actions 出 APK + Release | 本机不装 SDK |

**AI 设计原则**：模型只做"理解与挑选"，挑歌永远限定在用户曲库内（把候选歌的标签以结构化形式喂给模型，返回 ID 列表）；没配 key 时，星图、推荐用本地规则照样能用。

**隐私**：曲库特征全部本机计算；发给 AI 的只有歌名/歌手/标签，不传音频。设置页列清楚出网的每一条路径。

## 5. 视觉规范
- 浅色梦境：薰衣草 / 蜜桃 / 天空蓝三色渐变底，玻璃卡片（模糊 + 白色发丝边）
- 暖橙为唯一强调色（播放键、进度、我的气泡）
- 字少：一屏只说一件事；中文标题不加负字距
- 动效是功能的一部分：光球＝AI 状态，粒子环＝音乐本身，不做纯装饰的乱飘
- 性能底线：中端机 60fps；`BackdropFilter` 类模糊每屏控制在 1~2 块，其余用预模糊背景

## 6. 分期

| 阶段 | 内容 |
|---|---|
| M1 播放器本体 | 本地曲库、播放页、频谱粒子环、歌词、通知栏/小组件、主题取色 |
| M2 AI 伙伴 | 此刻首页、光球、对话点歌、天气/时间推荐、歌词解读 |
| M3 情绪星图 | 本机特征提取、星图、画线成歌单、情绪电台 |
| M4 扩展 | Navidrome/Jellyfin/WebDAV、听歌日记、AI 生成音乐、哼唱识别 |
