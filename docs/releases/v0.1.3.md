## 新增

- **网易云歌单同步整张**：以前车机接口每个歌单只给前 12 首，现在按歌单 ID 拿全部。私密歌单拿不到全部的，设成公开后再同步一次
- **界面重做**：纸白底加跟着封面颜色漂的柔光；标题换宋体（手机没有宋体时用黑体）；底栏选中项亮一颗光点
- **此刻**：微光想说的话放大放在中间；正在播放条带当前歌词和进度光；八颗心情光点；「哼一段 / 作一首」合成一条；常听的歌换大封面
- **曲库**：歌单封面铺满
- **播放**：歌名、歌词换宋体，顶上一枚状态标签
- 设置、引导页文案减字；没装音乐 App 时引导直接说可以用微光自带的曲库和电台

## 数据去哪
